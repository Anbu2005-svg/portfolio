## 📋 About This Project

This is an **interactive 3D portfolio website** showcasing AI/ML expertise, projects, and professional journey. Built with modern web technologies, it features a stunning animated user interface with real-time 3D graphics, smooth scroll animations, and responsive design.

### 🛠 Tech Stack

**Frontend:**
- **HTML** - 41.3% | Semantic markup with accessibility features
- **CSS** - 37.4% | Advanced styling with animations, glassmorphism, and responsive layouts
- **JavaScript** - 21.3% | Interactive features, animations, and 3D graphics

**Key Technologies:**

- CSS Grid & Flexbox for responsive layouts
- Custom cursor effects and scroll animations
- Netlify for deployment

### **Local Development**
```bash
# Clone the repository
git clone https://github.com/Anbu2005-svg/portfolio.git

# Navigate to project
cd portfolio

# Open with live server or local HTTP server
python -m http.server 8000
# or
npx serve
```

Then open `http://localhost:8000` in your browser.
